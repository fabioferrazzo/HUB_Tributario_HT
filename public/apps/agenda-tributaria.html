Atualização de dados

Atualizar mês

Por motivos de segurança do navegador (CORS), a busca automática usa uma função segura do HUB para consultar a fonte oficial da Receita Federal. Você também pode conferir a página oficial ou importar JSON manualmente.

Opção 1 — Consultar a fonte oficial

Abra a página oficial em uma nova aba e confira as datas. Útil para verificar se houve alteração ou prorrogação.

Abrir agenda oficial

Opção 2 — Atualizar automaticamente pela RFB

Busca a agenda oficial da Receita Federal para o mês selecionado e importa os vencimentos encontrados.

Opção 3 — Importar dados manualmente

Se você tem um JSON com os dados de outro mês (gerado pelo Claude ou pela sua equipe), cole aqui e o app atualiza:

💡 Dica: peça ao Claude — "gere o JSON da agenda tributária integrada de junho/2026 (Federal + RS + Municipal) no formato deste app" — e cole o resultado acima. O Claude consultará as três fontes oficiais (Receita Federal, SEFAZ-RS e legislação municipal) e devolverá o JSON pronto para importar.

Opção 4 — Automação completa (avançada)

Para atualização 100% automática, é possível configurar:

  • GitHub Actions + GitHub Pages: robô roda dia 1 de cada mês, faz scraping da Receita Federal e atualiza o JSON. Custo zero.
  • Cloudflare Workers + fetch: backend serverless faz proxy do site oficial, expõe API JSON. Custo zero até 100k requisições/dia.
  • Make.com (que você já usa): cenário mensal que extrai do gov.br, transforma em JSON e publica em URL fixa.

Posso te ajudar a montar qualquer uma dessas. A mais simples é a Make — leva ~30min para configurar e fica rodando sozinha.

Como compartilhar com sua equipe

Este é um arquivo HTML único e autônomo. Para que outras pessoas acessem por URL:

  1. GitHub Pages (recomendado): suba o arquivo num repositório → Settings → Pages → ative. URL fica em seu-usuario.github.io/repo. Gratuito.
  2. Netlify Drop: arraste o arquivo em app.netlify.com/drop. URL gerada na hora. Gratuito.
  3. Google Drive: não funciona para hospedagem direta de HTML, mas serve para compartilhar o arquivo.

Funciona offline?

Sim. Após a primeira visita, todos os dados ficam no cache do navegador. Você pode até instalar como aplicativo (ícone de download no topo) — ele aparece na tela inicial do celular ou no desktop, abre em janela própria e roda 100% offline.

Navegação

  • Setas ← → ou clique no nome do mês para abrir o seletor
  • Clique em qualquer data colorida para ver as obrigações
  • Clique em uma obrigação para expandir e ver código DARF, fundamento legal, período de apuração
  • Use os filtros do topo para ocultar categorias

Categorias

Federal (Receita Federal):

  • PF — Pessoa Física (IRPF, Carnê-Leão)
  • PJ Federal — Tributos federais principais (IRPJ, CSLL, PIS, Cofins, IPI)
  • PJ Acessórias — Declarações e escriturações (DCTFWeb, EFD-Reinf, ECD, DOI)
  • Retenções — IRRF, IOF, retenções na fonte
  • Simples / MEI — DAS, PGDAS-D, DASN-SIMEI
  • Servidor — CPSS de servidores civis

Estadual (SEFAZ-RS):

  • ICMS / RS — ICMS próprio (Apêndice III RICMS/RS), GIA-ICMS, GIA-ST, EFD ICMS/IPI, DeSTDA

Municipal:

  • ISS — Imposto Sobre Serviços (LC nº 116/2003 + legislação municipal). Atenção: o vencimento varia por município.
📍 Sobre as obrigações estaduais e municipais: as datas estaduais seguem a regra geral do RICMS/RS e da IN RE nº 064/2018 (alinhamento GIA + EFD ao dia 15). O ICMS próprio dia 12 é uma data de referência da categoria Geral — o Apêndice III do RICMS/RS prevê dezenas de prazos diferentes por CAE/atividade. Sempre confirme o prazo aplicável a cada cliente. O ISS varia de município para município (em geral entre dia 5 e dia 20).
⚖️ Aviso legal: Este app não substitui a consulta direta à Receita Federal. Sempre confirme prazos prorrogados, atos normativos supervenientes e particularidades setoriais no portal oficial antes de tomar decisões fiscais.
